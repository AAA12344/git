# 工单筛选字段清单

本文记录投诉管理各列表筛选栏与结构化工单数据之间的对应关系。字段路径以 `data/seed-data.json` 的运行时存储结构为准；同名字段在创建、处理、审批和查询导出页面复用同一字典与控件。

## 主工单通用筛选

适用页面：工单创建、工单处理、工单审批、查询导出－工单导出。

| 筛选条件字段名称 | 控件类型 | 对应工单实际字段 | 备注 |
|---|---|---|---|
| 工单类型 | 单选下拉 | `lists.tickets[].type` | 复用主工单类型字典；不包含舆情单。 |
| 工单状态 | 多选下拉 | `lists.tickets[].status` | 复用主工单状态机字典，不与子流程状态字典混用。 |
| 处置期限 | 日期范围 | `documentData.tickets[id].dispositionDeadline` | 使用开始日期、结束日期两个日期输入控件，固定占筛选栏 2 栏。 |
| 受理渠道 | 多选下拉 | `documentData.tickets[id].fields.entry.受理渠道` | 复用受理渠道字典。 |
| 工单编号 | 关键词输入框 | `lists.tickets[].id` | 支持按完整编号或编号片段查询。 |
| 短信审批状态 | 多选下拉 | `runtimeDefaults.smsStatusByTicket[id]` | 仅工单处理页面显示。 |
| 是否抄送 | 单选下拉 | `lists.tickets[].copiedTo` | 选项为“是／否”；具体按“存在任意抄送人”还是“当前用户被抄送”判断，待业务确认。 |
| 客户类型 | 单选下拉 | `documentData.tickets[id].fields.entry.客户类型` | 与客户姓名、联系方式固定放在同一行。 |
| 客户姓名 | 关键词输入框 | `documentData.tickets[id].fields.entry.客户姓名` | 与客户类型、联系方式固定放在同一行。 |
| 联系方式 | 关键词输入框 | `documentData.tickets[id].fields.entry.来电号码 / 预留手机号码 / 手机号码 / 联系方式` | 按多个客户联系电话字段进行关键词匹配。 |
| 机构范围 | 机构树多选 | 当前由 `documentData.tickets[id].fields.entry.工单接收机构` 提供 | 截图备注要求按投诉／信访／表扬机构筛选；建议单口径待业务确认。 |
| 所属业务条线 | 多选下拉 | `documentData.tickets[id].fields.entry.所属业务条线` | 结构为主条线加协办条线，筛选项按“或”匹配。 |

## 主工单投诉类扩展筛选

适用页面：选择“投诉单”后的工单处理、查询导出，以及配置了相同条件的报表详情。

| 筛选条件字段名称 | 控件类型 | 对应工单实际字段 | 备注 |
|---|---|---|---|
| 业务办理渠道 | 级联选择器 | `documentData.tickets[id].fields.entry.业务办理渠道标签` | 复用业务办理渠道标签树。 |
| 业务类别 | 级联选择器 | `documentData.tickets[id].fields.entry.投诉产品标签` | 复用投诉产品标签树。 |
| 投诉原因 | 三级级联选择器 | `documentData.tickets[id].fields.entry.投诉原因标签` | 复用三级投诉原因标签字典。 |
| 重复投诉 | 复选框 | 派生字段 | 同一客户、投诉产品标签中类相同，且两张投诉工单处于一个自然年内。勾选后剔除命中工单。 |
| 再次投诉 | 复选框 | `documentData.tickets[id].fields.processing.是否再次投诉` 加重复投诉派生结果 | 属于重复投诉的子集；单独勾选时“重复投诉”为部分选中。 |
| 异常投诉 | 复选框 | 关联异常投诉子流程及其认定结果 | 关联异常投诉子流程且认定结果为成功时命中。勾选后剔除。 |
| 废止投诉 | 复选框 | `lists.tickets[].status` | 工单状态为“已废止”时命中。勾选后剔除。 |

## 子流程通用筛选

适用页面：子单创建、子单处理、子流程审批、查询导出－子流程单导出。

| 筛选条件字段名称 | 控件类型 | 对应工单实际字段 | 备注 |
|---|---|---|---|
| 子流程类型 | 单选下拉 | `lists.subprocesses[].type` | 复用子流程定义字典。 |
| 子流程单状态 | 多选下拉 | `lists.subprocesses[].status` | 复用子流程状态机字典，不显示主工单专属状态。 |
| 处置期限 | 日期范围 | `documentData.subprocesses[id].dispositionDeadline` | 使用开始日期、结束日期两个日期输入控件，固定占筛选栏 2 栏。 |
| 子流程单编号 | 关键词输入框 | `lists.subprocesses[].id` | 与关联工单编号作为单据识别信息成组显示。 |
| 关联工单编号 | 关键词输入框 | `documentData.subprocesses[id].relatedTicketIds` | 支持一个子流程关联多个主工单编号。 |
| 子流程单创建人 | 关键词输入框 | `documentData.subprocesses[id].fields.base.创建人` | 与所属机构、所属部门固定放在同一独立行。 |
| 所属机构 | 机构树多选 | `documentData.subprocesses[id].fields.base.所属机构` | 与子流程单创建人、所属部门固定放在同一独立行。 |
| 所属部门 | 部门级联选择器 | `documentData.subprocesses[id].fields.base.所属部门` | 与子流程单创建人、所属机构固定放在同一独立行。 |

## 布局规则

- 筛选栏固定使用 4 栏网格；普通控件占 1 栏，日期／时间范围控件固定占 2 栏，不为塞入更多条件而压缩时间范围。
- 工单类型、状态、处置期限属于业务状态信息，合计占满 4 栏；受理渠道与工单编号、该页面独有的流程辅助条件放在下一行。
- 客户类型、客户姓名、联系方式属于客户信息，固定放在同一独立行；联系方式始终使用关键词输入框。
- 机构范围与所属业务条线属于业务归属信息，放在同一行。
- 子流程单编号与关联工单编号属于单据识别信息，放在同一行。
- 子流程单创建人、所属机构、所属部门属于创建归属信息，固定放在同一独立行。
- 产品、原因、渠道标签属于投诉分类信息，放在同一行。
- 剔除规则固定独占一行；多项规则按“或”命中后剔除。
